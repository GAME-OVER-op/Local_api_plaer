# Обновление 4.4

## Яркость в плеере

Вертикальный свайп по левой половине видео регулирует яркость только окна плеера от 5% до 100%.
Системная яркость Android не изменяется и дополнительных разрешений не требуется. Последнее значение
плеера сохраняется. Справа остаётся регулировка громкости, горизонтальный жест остаётся перемоткой.
Во время изменения поверх видео показывается `☀ N%`, даже если основные элементы управления скрыты.

## Улучшение изображения

В настройках появился раздел «Изображение» с отдельным включением обработки и профилями
«Оригинал», «Кино», «Насыщенный» и «Пользовательский». Пользовательский профиль позволяет
регулировать контрастность, яркость видеосигнала, насыщенность и гамму. Диапазоны намеренно
ограничены умеренными значениями, чтобы не срезать тени и светлые участки слишком агрессивно.

Коррекция выполняется штатным VLC video-filter `adjust`. Если конкретный декодер/устройство не
может запустить видео с этим фильтром, плеер один раз перезапускает текущий источник без коррекции,
не меняя сохранённые пользовательские настройки.

## HDR

HDR не имитируется повышением контрастности. На Android 7.0+ плеер проверяет метаданные
цветопередачи видео, когда это необходимо для защиты активной генерации кадров или SDR-коррекции.
Распознаются PQ/ST2084 (HDR10), HLG, статические HDR-метаданные и Dolby Vision по MIME контейнера.

Если источник определяется как HDR, плеер отключает для текущего видео генерацию кадров и SDR
коррекцию изображения и перезапускает воспроизведение через прямой видеовывод VLC с сохранением
позиции. Следующий SDR-файл снова использует выбранные пользователем настройки. Возможности HDR
экрана проверяются отдельно через Android HdrCapabilities.

На Android ниже API 24 новые HDR API не загружаются; приложение продолжает использовать обычный
путь воспроизведения, поэтому минимальная версия Android остаётся API 19.

## Проверка

Проверены XML-ресурсы, все новые `R.id`, типы элементов настроек, структурный синтаксис изменённых
Java-файлов и сохранность исправлений предыдущей версии (аудио при генерации кадров, индикатор
громкости и полная загрузка файлов до 50 MiB). В текущем окружении нет Android SDK/Gradle, поэтому
полная APK-сборка здесь не выполнялась; финальная компиляция остаётся за GitHub Actions проекта.

На реальном устройстве рекомендуется проверить SDR и HDR10/HLG ролики, аппаратный и программный
декодер, включение/выключение генерации кадров, все четыре профиля изображения, возврат из настроек,
свайпы яркости/громкости и воспроизведение после поворота экрана.
